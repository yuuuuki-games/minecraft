# YuuuuKi制作 Minecraft配布ワールド


## ワールドのダウンロード統計

Release の添付ファイルの累計ダウンロード数を、日本時間の実行時点ごとに表示します。
履歴はこの方式での最初の実行日から記録されます。添付ファイルが削除された場合など、
GitHub API から取得できる対象ファイルが減ると、合計値も減少することがあります。
